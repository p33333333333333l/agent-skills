## 选择访问方式

1. 优先已登录、实际可读、成本明确的渠道。扩展界面适合少量竞品，已授权 MCP/CLI 适合结构化读取；免费渠道补足趋势、SERP 与市场证据。
2. 浏览器工具先发现现有标签页，在独立后台页读取公开目标，保持用户已有会话。以当前工具 schema 和实际 DOM 为准。
3. 用界面或已授权账号状态核对可用功能；查看当前套餐、余额、扣费规则。只读也可能消耗 credits。调用前限定候选域名、页数、时间窗与可消耗上限。
4. 浏览器桥断连时请用户重连一次，再继续其他公开渠道。扩展弹窗或侧边栏不在可访问 DOM 中时，使用能可靠触达的扩展页面、官方导出或用户截图；报告“未读取会员数据”，不猜坐标或捏造接口。

安装扩展、MCP 连接成功和非空数据返回分别验收；只有最后一项证明完成了相应取数。浏览器登录不会自动给终端 OAuth 或 API 权限。

## AITDK

当前官网把流量、页面 SEO、关键词密度、WHOIS 等作为研究入口；定价页说明核心分析工具免费，Backlinks 与 Reverse AdSense 查询消耗 credits，套餐区别还包括流量历史长度和来源详情。按当前账号与版本核对，而不是假定所有深度数据都免费。

- 先读域名概览，记录报告域名、流量单位、时间窗、主要地区、渠道和更新时间；缺数据时保留未知。
- 关键词密度分析用于读取页面用词和主题，不等于该站真实获客关键词、月搜索量或自然排名。若当前版本另有查询词报告，先验证字段和数据来源，再区别有机、付费、品牌与非品牌；记录实际展示行数和截断部分。
- 页面分析可辅助核实标题、H1、索引相关标记与页面意图，但不证明该页面排名或产生付费转化。
- 本机扩展清单核验到工具栏入口 `popup.html`，当前官网则描述页面旁面板。两者不能直接等同；先发现当前版本的真实入口与可读 DOM，再确认它能初始化并绑定目标标签。不可读时用截图/导出。

扩展 ID 可通过官方商店链接定位；当前清单与页面是实际接口，版本与字段运行时发现。AITDK 网站的 AI Keywords Generator 生成建议文案，不是市场需求数据。AITDK 和 SiteData 的估算可能依赖相同底层来源，不能默认独立。

### 界面取数

- **免费/订阅内读取：** 核实流量、Domain Lookup、DR 等是否在当前账号和当前入口标记为免费或不扣额度。官网价格页列出部分免费接口，不代表所有 SEO/关键词方法同样免费。
- **候选发现：** 流量增长、新站、分类或支付网关来源榜单只用于生成候选；先排除不匹配的地域、商业模式、品牌和信息站，再读取少量匹配竞品。
- **广告与网络：** 广告素材用于观察价值主张；Reverse AdSense 可提供站点关联线索，但相同 Publisher ID 不足以确认所有权。查询和监控可能扣额度；监控是持续操作，不随一次调研自动启用。
- **导出：** 优先界面可用的官方导出；保留域名、日期、筛选条件、供应商字段和行数。若只有截图，可录入实际可见行并注明覆盖不足，不补齐未显示的数据。
- 本机核验到的扩展形态为 `sidepanel.html`。侧边栏不等于普通网页 DOM；先验证浏览器工具能读取，失败按上面的截图/导出路径降级。

## SiteData 官方 MCP/CLI

官网当前提供 OAuth MCP 与官方 CLI。Starter 的榜单访问权益按上表采用；连接/安装入口免费不代表所有数据调用免费。具体方法、费用和授权以当前账号、Catalog 和价格页为准，浏览器会员不是无限 API 额度。

### 已有授权

- **MCP：** 发现当前客户端已连接的服务及实际工具 schema，只调用真实存在的只读方法。官方远程端点为 `https://mcp.sitedata.dev/mcp`，支持浏览器授权。读取分页时核对总量、游标和实际行数。
- **CLI：** 官方包名为 `@sitedata-dev/cli`。同一运行环境下先核对 `sitedata auth status`，再用 `sitedata list --output json` 读取在线 Catalog；目标命令用 `sitedata describe <command> --output json` 查参数，按当前契约请求 JSON。
- **额度：** 调用前核对方法是否扣费、余额与本轮预算。遇到套餐锁、未知扣费、额度耗尽或授权失败，停在受限结果；不试购更高套餐，也不重复调用碰运气。

### 尚未连接

若用户本轮明确授权连接或安装，按官方安装指南和当前客户端文档实施；否则先交付浏览器/免费渠道结果，说明连接能解决的具体缺项，不顺手改全局配置。

OAuth 需要用户在浏览器完成授权；使用工具的人机交接能力。CLI 的系统用户与运行环境必须一致：Brave、Flatpak、宿主机、容器或远端环境并不自动共享凭据。安装并登录后，先用账号状态和 Catalog 验收；在额度规则确认前不以付费榜单请求作连接测试。

不读取浏览器 Cookie、扩展存储或系统凭据来搬运会员权限。使用官方 OAuth/用户提供的受支持认证；授权码、回调 URL、令牌和完整账户信息不写入仓库或报告。

## 指标解释与阻塞

插件竞品流量按供应商估算记录，附月份、域名、国家与设备范围；与自有站 Search Console 数据分栏。小站无数据、`N/A`、界面占位符都不转换为 0。DR 是供应商的域名指标，不是 Google 指标或某个词的 KD。

| 情况 | 行动与结果标签 |
| --- | --- |
| 桥断连或浏览器不可用 | 请求重连/启动一次，继续公开来源；会员取数标为未完成 |
| 验证码、登录、OAuth | 交给用户完成该步骤；用户取消则停止该路径 |
| 弹窗/侧边栏不可读取 | 使用官方导出或截图；不足部分保持未知 |
| 401/403、签名接口、套餐锁 | 按授权/权限阻塞处理；不伪造签名或猜内部端点 |
| 429、额度耗尽 | 停止当前来源，保留已取数据与失败原因；不更换身份绕限额 |
| 估算冲突或缺市场范围 | 并列原始口径，降低置信程度，补真实页面/自有站证据 |
